Seguridad y gobierno de datos

Construir con IA no significa entregar tus registros a un tercero. Así protegemos la información sensible, mientras diseñamos y en todo lo que construimos.

Cómo usamos la IA

  • Construido con datos de prueba

    La IA escribe y prueba el código con datos inventados o anonimizados. Tus registros nunca van a un modelo de IA mientras construimos.

  • El código hace el trabajo

    Lo que entregamos lee, clasifica y redacta siempre de la misma forma, dentro de tus sistemas.

  • IA en sistemas en producción

    Si un sistema usa IA mientras funciona, lo hace por la API empresarial de Anthropic, cuyos términos no permiten usar los datos para entrenar modelos de IA. Nunca apps de chat para consumidores.

  • Datos sensibles fuera

    Datos como números de seguro social y cuentas bancarias se ocultan o se dejan fuera de lo que ve la IA.

  • Las personas aprueban

    Una persona aprueba todo lo que mueve dinero, cambia un registro o te compromete con un cliente.

  • Registro completo de actividad

    Cada acción que prepara el sistema queda registrada con quién la aprobó y cuándo.

Acceso y almacenamiento

  • Tus sistemas, tus datos

    Siempre que es posible construimos dentro de tu propio entorno, como Microsoft Azure, y no guardamos copias.

  • Acceso de mínimo privilegio

    Cuentas separadas con solo el acceso que el trabajo necesita, que se eliminan al terminar.

  • Solo lectura mientras diseñamos

    Nada cambia en tus sistemas durante el Diseño de la solución.

  • Secretos en una bóveda

    Las claves de API y contraseñas se guardan en el servidor, por ejemplo en Azure Key Vault, nunca en el código.

Acuerdos y cierre del proyecto

  • NDA si lo pides

    Firmamos un acuerdo de confidencialidad o de tratamiento de datos si lo solicitas.

  • Devueltos o eliminados

    Al terminar el proyecto, tus datos se devuelven o se eliminan.

Preguntas de tu equipo de TI o de seguridad

Envíalas a alexp@khipuai.co o plantéalas en una llamada de descubrimiento gratuita. Por favor no envíes contraseñas ni registros de clientes por correo; primero acordamos una forma segura de compartirlos.

Estamos convirtiendo estas prácticas en políticas y procedimientos que tu equipo de TI puede revisar; cada uno aparecerá aquí cuando esté listo. Cómo este sitio maneja tus datos se explica en la política de privacidad.
